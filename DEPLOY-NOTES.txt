COMPUDON JUNIOR — DEPLOYMENT NOTES
Package prepared 17 August 2026

--------------------------------------------------------------------
IMPORTANT: form-handler.php IS NOT IN THIS ZIP
--------------------------------------------------------------------
It was deliberately left out. The live copy contains the SMTP mailbox
password, the Zoho client secret and the Zoho refresh token. Including
it here would overwrite those with blanks and break email sending.

form-handler.php is being supplied separately.

If the separately supplied file is used, confirm line 43 still has the
mailbox password filled in:

    define('SMTP_PASSWORD', 'the-password');

An empty '' there means no email can be sent by any form on the site.

--------------------------------------------------------------------
WHERE FILES GO
--------------------------------------------------------------------
Unzip into the web root (normally public_html), preserving folders.
Overwrite existing files. Nothing needs to be renamed or moved.

Required adjacency (do not change):
  public_html/
    index.html
    register-school.html
    form-handler.php        <- same folder as index.html
    phpmailer/              <- must sit INSIDE the same folder
    assets/downloads/...

form-handler.php is called by the form as fetch('form-handler.php')
with no path, so it must be in the same folder as the page. The handler
loads PHPMailer via __DIR__ . '/phpmailer/', so that folder must be
directly alongside it.

phpmailer/ is unchanged from the previous deployment and is already on
the server. It is included only as a fallback.
